# FALL-AIRGAP — the 6-byte air-gap transport

**Live: https://sjgant80-hub.github.io/fall-airgap/**

The internal mesh stops speaking JSON and speaks raw byte-coordinates. A real estate state-event — a capability delegation, a gate verdict, a heartbeat, a pipeline step — becomes the SENTINEL 6-byte Primorial-Fold packet, signed with Ed25519, **verified before it is ever parsed**, and pushed over a bidirectional channel (WebRTC DataChannel / WebSocket / NFC / acoustic FSK) with **no HTTP handshake or header bloat**. That stream is "the Air" inside the machine.

This repo is the **transport** and the **measurement**. The codec and the signature-first gate are [SENTINEL](https://sjgant80-hub.github.io/sentinel/)'s live, mutation-gated kernel — reused here, not re-invented.

## The 42–100× claim, measured in real wire bytes

The number the 15× test never measured. Counted by the kernel in real UTF-8 bytes:

| event | JSON | 6-byte coordinate | 1-byte delta | signed-per-packet (71B vs signed-JSON) |
|---|---|---|---|---|
| capability_delegation | 186 B | **31×** | — | 3.99× |
| gate_verdict | 171 B | **28.5×** | — | 3.77× |
| heartbeat | 136 B | **22.67×** | **136×** | 3.28× |
| pipeline_step | 145 B | **24.17×** | **145×** | 3.41× |
| antibody | 136 B | **22.67×** | — | 3.28× |

**Read it honestly.** The 6-byte coordinate beats self-describing JSON **22.67–31×**; a recurring deterministic step sent as a **1-byte delta** hits **136–145×** (the receiver recomputes the step locally). But sign *every* packet and the **64-byte Ed25519 signature is irreducible** — per packet it is only **3.28–3.99×**. The headline 42–100× is real **only when one handshake signature authenticates a whole session** and coordinates then stream over it. Signatures (64 B), SHA-256 hashes (32 B) and novel human prompts sit at their entropy floor and do not compress.

| transport | status |

"Measured" means it ran in the browser. Nothing here claims a radio ran.

## The six bytes

```
[0] opcode   [1] (source<<4)|target   [2] resource bitmask   [3..4] budget uint16 LE   [5] κ-witness fold
```

On the wire, signed: `[sourceId:1][payload:6][signature:64] = 71 bytes`. The gate verifies the Ed25519 signature **before** the six bytes reach a DataView — an unverified command never compiles into a command. A rejected command is dropped into a zero-budget phantom cell; with no capability budget, lateral movement is mathematically impossible.

## The reroute trigger (Simon's open question, answered)

*Reroute the moment the signature fails, or watch the maze first?* **Tier it by what the failure tells you:**
- **Crypto failure** (forged / unknown-source / replay) → **seal now.** A forger carries zero intelligence and every millisecond near real state is risk. No error returned (an error confirms a real door was found).
- **Policy failure from an authenticated source** (budget-exceeded / resource-denied / off-κ) → **maze first.** The key is real (a compromised insider), so the lateral-movement intent is worth fingerprinting — and it is safe to watch, because the phantom's zero budget means they can pivot nowhere.
